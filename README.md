# sales-data-analysis
Sales performance analysis using Python, Pandas and Matplotlib

## About the Project
In this project, I worked with a small sales dataset to understand how different products, categories and regions perform.  
The goal was to practice data analysis using Python.

## What I Did
- Loaded and cleaned the dataset  
- Removed duplicate records  
- Created a new column called Revenue (Price × Quantity)  
- Analyzed sales based on category, product and region  
- Visualized the results using bar charts and line plots  

## Key Observations
- Electronics category generated the highest revenue  
- Some products contribute more compared to others  
- Certain regions performed better in terms of sales  
- Sales vary across different dates  

## Tools Used
- Python  
- Pandas  
- Matplotlib  

## Files
- `project.py` → contains the code  
- `sales.csv` → dataset used  

## Conclusion
This project helped me understand how raw data can be cleaned, analyzed and converted into useful insights.
